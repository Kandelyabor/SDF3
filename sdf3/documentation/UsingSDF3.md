# Using SDF3

The SDF3 toolset consists of a number of separate domains and executables

- SDF
- CSDF
- FSM-SADF
- SADF

## SDF

The following executables are associated with this domain (on Windows with `.exe` extension)

- `sdf3analyze-sdf`
- `sdf3flow-sdf`
- `sdf3generate-sdf`
- `sdf3print-sdf`
- `sdf3transform-sdf`

For documentation of these functions see [UsingSDF3-SDF.md](./UsingSDF3-SDF.md)

## CSDF

The following executables are associated with this domain.

- `sdf3analyze-sdf`
- `sdf3generate-csdf`
- `sdf3print-csdf`
- `sdf3transform-csdf`

For documentation of these functions see [UsingSDF3-SDF.md](./UsingSDF3-CSDF.md)

## FSM-SADF

The following executables are associated with this domain.

- `sdf3analyze-fsmsadf`
- `sdf3flow-fsmsadf`
- `sdf3generate-fsmsadf`
- `sdf3transform-fsmsadf`
- `sdf3inputconvert-fsmsadf`
- `sdf3outputconvert-fsmsadf`

For documentation of these functions see [UsingSDF3-FSM-SADF.md](./UsingSDF3-FSM-SADF.md)

## SADF

The following executables are associated with this domain.

- `sdf3analyze-sadf`
- `sdf3convert-sadf-csdf2sadf`
- `sdf3convert-sadf-sadf2csdf`
- `sdf3convert-sadf-sadf2fsmsadf`
- `sdf3convert-sadf-sadf2sdf`
- `sdf3convert-sadf-sdf2sadf`
- `sdf3print-sadf`
- `sdf3verify-sadf`

For documentation of these functions see [UsingSDF3-SADF.md](./UsingSDF3-SADF.md)
